## Login System (Python)

# Overview
This project is a *python-based Login System* designed to handle basic user authentication workflows, including user registration, login validation and access control.

The goal of this project was to strengthen my understanding of program flow, conditional logic, data handling, and state management in python. Rather than relying on external libraries, the system focuses on core python concepts and clean logic implementation.

## Features
- User registration
- Secure login authentication
- Username and password validation
- Error handling for invalid credentials
- Logical access control flow
- Persistent or in-memory user data handling

## Technology Used
- Python 3
- Standard python libraries 

# How To Run
1. The program prompts the user to either **register** or **log in**
2. During registration:
- User credentials are validated
- New data is stored
3. During login:
- Input credentials are checked against stored data
- Access is granted or denied based on correctness
4. The system ensures:
- Incorrect credentials are handled safely
- Users receive clear feedback

##  Learning Outcomes
Through this project, i learned and reinforced:
- Program flow control using conditional and loops
- Data validation and comparison 
- Handling user input securely and logically
- Importance of clean indentation and structure
- How real authentication logic works at a basic level

This project significantly improved my confidence in writing *structured python programs* and understanding how backend authentication systems operate.
